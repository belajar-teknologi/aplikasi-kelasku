Fitur Lengkap Guru

Semua Kebutuhan Administrasi Kelas Dalam Satu Aplikasi

Dirancang khusus untuk mendukung kegiatan mengajar guru secara efisien tanpa repot berkas manual.

Presensi Kehadiran Digital

Catat status Hadir, Sakit, Izin, dan Alpa dengan tombol cepat. Fitur "Tandai Semua Hadir" dan kirim rekap langsung ke WhatsApp wali murid.

Buku Nilai & Rekap KKM

Hitung nilai tugas, kuis, UTS, UAS secara otomatis. Dilengkapi indikator ketuntasan KKM dan pengiriman rapor ringkas ke WhatsApp/Email.

Kuis Daring & Link Soal

Buat kuis pilihan ganda, bagikan link/kode kuis ke siswa, serta lakukan simulasi ujian interaktif dengan timer dan penilaian otomatis.

Export Laporan PDF

Cetak dan simpan rekapitulasi kehadiran dan kemajuan nilai siswa dalam format dokumen PDF resmi siap setor ke kepala sekolah.

Kalender & Tugas Rumah

Atur jadwal ulangan, tenggat PR, dan agenda rapat dengan integrasi pengingat notifikasi agar tidak ada agenda yang terlewat.

Chat Interaktif Wali Murid

Komunikasi langsung per siswa dengan template pesan cepat untuk konsultasi perkembangan belajar siswa.

Informasi Repositori & Cara Membuka Proyek

Repositori ini berisi kode sumber aplikasi **Android Native** (Kotlin + Jetpack Compose).

Buka di Android Studio

  1. Clone repository ini ke komputer Anda.
  2. Buka software Android Studio.
  3. Pilih Open Project dan arahkan ke folder ini.
  4. Tunggu proses Gradle Sync selesai.
  5. Klik tombol Run (Play Hijau) untuk menjalankan di HP atau Emulator.

Jalankan di Google AI Studio

  1. Buka workspace di Google AI Studio Build.
  2. Aplikasi langsung aktif di Streaming Emulator sebelah kanan.
  3. Gunakan menu Export / Download APK untuk memasang di HP.

Pilihan Unduh APK

Asisten Guru Pintar • File .apk siap pasang

1. Unduh via GitHub Actions (Otomatis)

Setiap push ke GitHub otomatis men-generate file APK di tab Actions.

Buka Tab GitHub Actions & Download APK

2. Unduh via Google AI Studio

Di panel Google AI Studio, buka menu titik tiga di pojok kanan atas → pilih Download / Export APK.

3. Build Sendiri di Android Studio

Buka project di Android Studio → menu Build → Build Bundle(s) / APK(s) → Build APK(s).
